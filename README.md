# Aru — личный стилист в телефоне

Aru собирает цветотип, причёску, одежду, аксессуары, макияж и готовые образы
в одну панель стиля — как будто девушку одевал один стилист, от причёски до обуви.
Три языка: қазақша, русский, English.

## Что в репозитории

| Папка | Что внутри |
| --- | --- |
| `app/` | Прототип приложения (`index.html`) |
| `landing/` | Трёхъязычный лендинг (`index.html`) |
| `demo/` | Демо-клиентки Айгерим и Елена (изображения созданы ИИ) |
| `docs/` | Описания продукта, карточка Gumroad, презентации |
| `protocols/` | Протоколы этапов: номер_дата_тема (PowerPoint и PDF) |

## Правило архивов

После каждого завершённого этапа:

1. Все изменения сохраняются в этот репозиторий.
2. Ставится метка версии: v0.1, v0.2…
3. Выпускается Release — GitHub сам собирает ZIP всего проекта.
4. ZIP скачивается на компьютер в папку «Aru / Архив».
5. Пишется протокол со следующим номером.

## Карта папок на компьютере

Папка проекта: `M:\ __ 0000 __ ARU ЛИЧНЫЙ СТИЛИСТ`

| Папка | Что внутри |
| --- | --- |
| 00_Входящие | Всё новое из чата и Gemini; разбираем в конце этапа |
| 01_Протоколы | Протоколы 01, 02, 03… (PowerPoint и PDF) |
| 02_Архивы | ZIP-архивы версий: Aru_архив_vX.X_дата.zip |
| 03_Документы | Действующие описания и презентации |
| 04_Демо-клиентки | Айгерим (анкета, Исходник, Примерки), Елена (Исходник, Примерки) |
| 05_Gumroad | Карточка товара, обложки, инструкция покупателю |
| 99_Старое | Устаревшие версии |

Правила: всё новое сначала в 00_Входящие; разбор в конце этапа; новая папка — только по договорённости, сразу в эту карту и в протокол.
